# Function: getSentimentPalette()

> **getSentimentPalette**(`n`, `mode?`): [`SentimentPalette`](../type-aliases/SentimentPalette.md)

## Parameters

### n

`number`

The number of positive/negative sentiment levels [1-3]

### mode?

[`ColourMode`](../enumerations/ColourMode.md) = `ColourMode.Light`

Which colour mode (dark/light) should the returned palette be suitable for?

## Returns

[`SentimentPalette`](../type-aliases/SentimentPalette.md)

An object defining a colour palette suitable for visualising sentiment
